# Security Policy

## Reporting

Do not publish exploitable security details in a public issue. Contact the repository owner through the private contact methods on the [Kirch-Nairu profile](https://github.com/Kirch-Nairu).

Include the affected component, reproduction conditions, potential impact, and any safe mitigation already identified.

## Scope

Security-sensitive areas include:

- deployment configuration and credentials;
- browser storage and user-provided data;
- dependency and supply-chain integrity;
- GitHub Actions permissions;
- external links, embeds, and generated assets;
- recovery and rollback behavior.

No secret, token, private key, or production credential belongs in this repository.
