# Agent Instructions

## Repository principles

- Reality over recollection.
- Evidence over claims.
- Complexity must pay rent.
- Preserve established Kirion identities and terminology.
- Keep changes bounded and reviewable.
- Do not fabricate tests, metrics, users, deployments, or external validation.

## Before editing

Read the relevant canon, architecture, and contribution documents. Inspect the current worktree and preserve unrelated changes.

## Verification

Run the narrowest relevant checks first. Record verification in the pull request. Visual changes require visual inspection; behavior changes require executable evidence.
